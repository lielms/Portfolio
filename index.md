## Professional Self-Assessment
	
My work throughout the SNHU computer science program has focused on building reliable software, selecting appropriate data structures and algorithms, and communicating technical decisions clearly. Across numerous courses, I have developed applications in Java, C++, and Python, gaining experience in full stack development, secure coding, testing, database integration, and much more while working both independently and in team settings.
Throughout the program I implemented and analyzed common data structures such as arrays, linked lists, stacks, queues, and maps. I applied Big O analysis to evaluate performance and guide design choices. This experience can be seen in my linked list assignment, where I refactored a simple singly linked list into a generic doubly linked list and added an efficient merge sort algorithm.
My strongest growth has been in software engineering practices such as separation of concerns, testability, and modular design. I learned to refactor code to reduce duplication, define clear interfaces, and design systems that are easier to extend and test. I also gained experience working with databases, including relational concepts in earlier courses and NoSQL integration later. In the programs capstone, I integrated MongoDB into a Python based thermostat project to persist system state and historical data without disrupting real time behavior.
Security has been a constant consideration in my work, particularly through defensive programming and strict input validation. I focused on validating data at system boundaries, handling errors safely, and ensuring systems behave predictably when given invalid input or when dependencies fail. These practices reduce the risk of crashes, inconsistent state, or unsafe behavior.
The artifacts in this portfolio represent different but connected areas of my skill set. The Java contact management system demonstrates software design, testing, and validation. The C++ linked list highlights data structures, algorithms, and performance considerations. The Python thermostat project shows system integration, database usage, and interaction with hardware. Together, they reflect my ability to design, implement, test, and reason about software systems across multiple languages and environments. Although I am just beginning my professional career, I recognize that there is still much to learn. What I may lack in industry experience, I make up for with a strong foundation in core computer science concepts and a willingness to continuously learn, adapt, and improve.
